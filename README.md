### Como Submódulo Git (Recomendado)
Para vincular a skill a qualquer novo projeto e receber atualizações automáticas:
```bash
git submodule add https://github.com/marquesbelem/camis-game-dev-setup-web-game-skill.git .agent/skills/setup-web-game
```

# Informações para gerar a Skill de Setup Web Game

A Skill tem como objetivo preparar um projeto seguindo as informações abaixo. 
- Use o Phaser 3 para fazer jogo 2D.
- Use o  Babylon.js para fazer jogo 3D.
- Não gerar assets sem solitação, usar formas geometricas  coloridas para diferenciar os elementos e deixar já um lugar onde separado aonde tem a opção de trocar para o assets que for inserido no projeto futuramente, com os trigger
  para animação e sons já configurados.
- Manter rigorosamente cada sistema separado com suas responsabilidades definidas. 
- Comentario no codigo em portugues. (Comentários com critério)
- Nome de arquivos e o codigo em ingles.
- Use o padrão de observable, arquitetura orientada a evento.
- Tamanho e carregamento do arquivo: Telas de carregamento e Carregamento progressivo.
- Prioridade para dispositivos móveis.
- Foco em desempenho: taxa de quadros (FPS), uso de CPU, GPU e memória RAM, tempo de carregamento e rede, e latência de entrada.
- Clean Code:Funções pequenas, DRY (Don't Repeat Yourself), KISS (Keep It Simple, Stupid), Tratamento de erros claro, Coesão e baixo acoplamento.
